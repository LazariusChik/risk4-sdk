# Changelog

## SDK preview

- Public headers and stripped RV32 `core` / `full` libraries for native apps.
- Four buildable examples: Hello, Hello 2D, Hello 3D and Pentest.
- Build, ELF validation and `.pelf` packaging tools.
- Guides for app isolation, memory hardening, hardware access and graphics.
- System walkthrough, Minecraft server demo and earlier ProtoOS showcase.
- Kernel ABI 26, loader ABI 5, manifest v5; RV32 / `ilp32f`.

Firmware is distributed separately. The kernel and runtime/graphics
implementation sources remain private.
