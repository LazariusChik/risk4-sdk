## Minecraft server on ProtoOS

[Watch the Minecraft server demo on Reddit](https://www.reddit.com/r/embedded/comments/1vzbtl2/a_server_for_minecraft_1218_in_c_that_runs_on_the/)

A native C server for Minecraft 1.21.8 running on an ESP32-P4 under ProtoOS.
The Minecraft client runs on a PC and connects to the board over the network.
This demonstrates a networked application built on the platform.
